# 部署（Linux + systemd + Tailscale）

看板只该在内网里访问。下面以 Tailscale 为例；别的内网方案（WireGuard、只开本机）同理。

1. 在服务器上拿到内网 IP：`tailscale ip -4`。
2. 建目录和用户：
   ```
   sudo mkdir -p /opt/ai-board /var/lib/ai-board
   sudo cp server.py board.py /opt/ai-board/
   sudo useradd --system --no-create-home --shell /usr/sbin/nologin aiboard
   sudo chown aiboard /var/lib/ai-board
   ```
3. 生成口令，写进 `/etc/ai-board.env`（权限 600，归 root）。口令不要贴进聊天、笔记或仓库：
   ```
   BOARD_TOKEN=<python3 -c "import secrets;print(secrets.token_urlsafe(32))" 的输出>
   BOARD_HOST=<第 1 步的内网 IP>
   BOARD_PORT=8765
   BOARD_DB=/var/lib/ai-board/board.db
   ```
4. systemd 服务 `/etc/systemd/system/ai-board.service`：
   ```
   [Unit]
   Description=AI shared task board
   After=network-online.target tailscaled.service

   [Service]
   User=aiboard
   EnvironmentFile=/etc/ai-board.env
   ExecStart=/usr/bin/python3 /opt/ai-board/server.py
   Restart=always

   [Install]
   WantedBy=multi-user.target
   ```
   `sudo systemctl enable --now ai-board`
5. 每天备份（cron，按星期轮换，留 7 份）：
   `sqlite3 /var/lib/ai-board/board.db ".backup /var/lib/ai-board/backup-$(date +%u).db"`
6. 自测：`curl http://<内网IP>:8765/health` 返回 `{"ok": true}`；带错口令请求 `/tasks` 返回 401。
7. 确认 8765 端口从公网访问不到。

## 客户端

每台机器建 `~/.config/ai-board.env`（权限 600）：

```
BOARD_URL=http://<内网IP>:8765
BOARD_TOKEN=<口令>
BOARD_ACTOR=<这台机器上的 AI 叫什么>
```

几个 AI 共用一台机器时，共用这份文件，运行时用环境变量 `BOARD_ACTOR=...` 覆盖名字。

建议每天定时跑一次 `board export <镜像路径>.md`，把镜像提交进你们的笔记仓库。服务挂了，大家先读镜像。
